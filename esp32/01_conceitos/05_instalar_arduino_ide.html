Instalar a Arduino IDE para ESP32 (Windows)

Nao precisa de administrador se voce usar a versao "Windows ZIP file" ou instalar so para o seu usuario.

Passo 1 - Baixar: acesse arduino.cc/en/software e baixe a Arduino IDE 2 para Windows. Instale ou extraia o ZIP e abra.
Passo 2 - URL de placas: menu Arquivo > Preferencias. No campo URLs adicionais para Gerenciador de Placas cole: 
https://espressif.github.io/arduino-esp32/package_esp32_index.json
Clique OK.
Passo 3 - Instalar o pacote: abra o Gerenciador de Placas (icone da lateral esquerda), pesquise esp32 e instale esp32 by Espressif Systems, versao 3.x. Demora (baixa varios arquivos). Os exemplos deste curso usam o core 3.x.
Passo 4 - Driver USB: se o Windows nao reconhecer a placa, instale o driver do chip: CP210x (Silicon Labs) ou CH340 (WCH). Veja a escrita no chip da placa. Placas S3 com porta USB "nativa" geralmente nao precisam.
Passo 5 - Escolher placa e porta: menu Ferramentas > Placa > esp32: escolha ESP32 Dev Module (ou ESP32S3 Dev Module). Depois Ferramentas > Porta e marque a COM da placa.
Passo 6 - S3 com USB nativo: em Ferramentas ligue USB CDC On Boot: Enabled para o Serial funcionar pela porta USB nativa.
Passo 7 - Monitor Serial: abra Ferramentas > Monitor Serial e escolha 115200 baud, o mesmo valor do Serial.begin(115200).
Se aparecer "Failed to connect... Wrong boot mode": segure o botao BOOT da placa, clique em Carregar e solte o botao quando aparecer "Connecting...". Se a porta nao aparece, troque o cabo (alguns so carregam, nao transmitem dados).
