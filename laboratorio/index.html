CONSTRUA UMA BASE SÓLIDA

Teoria da programação

Antes de escrever código, entenda como transformar um problema em passos claros. Abra cada tópico para estudar o conceito e ver um exemplo.

01Algoritmos e sequênciaUma solução é uma sequência ordenada de instruções.

Um algoritmo descreve, em passos finitos e compreensíveis, como resolver um problema. A sequência importa: primeiro obtemos os dados, depois processamos e, por fim, apresentamos o resultado.

ler largura
ler altura
area = largura * altura
mostrar area

Esse raciocínio funciona antes de escolher a linguagem. O programa em C ou C++ traduz cada passo em instruções que o computador pode executar.

02Variáveis, tipos e memóriaDados têm significado, representação e espaço reservado.

Uma variável é um nome associado a um valor guardado durante a execução. O tipo informa quais valores são esperados e quais operações fazem sentido: inteiros para contagens, números decimais para medidas e texto para palavras.

int quantidade = 3;
double temperatura = 24.5;

Escolher tipos adequados deixa o programa mais claro e ajuda a evitar conversões e resultados inesperados.

03Decisões e condiçõesO programa pode escolher caminhos diferentes.

Uma condição é uma expressão que resulta em verdadeiro ou falso. Estruturas como if e else usam esse resultado para decidir qual bloco executar.

if (temperatura >= 30) {
    printf("Ligar ventilacao");
} else {
    printf("Temperatura normal");
}

Compare os limites com atenção: incluir ou não o valor-limite muda o comportamento do programa.

04Repetições e laçosAutomatize tarefas sem copiar as mesmas instruções.

Um laço repete um bloco enquanto uma condição é satisfeita ou por uma quantidade definida de vezes. Em qualquer repetição, identifique como ela começa, quando termina e o que muda a cada passo para evitar um laço infinito.

for (int i = 0; i < 5; i++) {
    printf("%d\\n", i);
}

Use for quando a contagem é conhecida; while é útil quando a repetição depende de uma condição.

05Funções e organizaçãoDivida problemas grandes em partes menores e reutilizáveis.

Uma função recebe dados de entrada, executa uma responsabilidade e pode devolver um resultado. Nomes claros e responsabilidades bem definidas facilitam a leitura, os testes e a manutenção.

double calcular_area(double largura, double altura) {
    return largura * altura;
}

Parâmetros são os dados recebidos; o valor de retorno é o resultado entregue ao código que chamou a função.

06Vetores, endereços e ponteirosAprenda a agrupar valores e como C representa a memória.

Um vetor guarda vários elementos do mesmo tipo em posições numeradas a partir do índice zero. Em C, um ponteiro guarda um endereço de memória; usá-lo requer cuidado com inicialização, limites e tempo de vida dos dados.

int notas[3] = {8, 9, 10};
int *primeira_nota = &notas[0];

C++ oferece ferramentas de nível mais alto, como std::vector, que gerenciam coleções com mais segurança. Entenda primeiro o conceito, depois escolha a ferramenta apropriada.

GUIA ACADÊMICO
Referências bibliográficas (ABNT NBR 6023)
Como citar livros, artigos, sites e documentações nos seus trabalhos, com modelos, gerador e bibliografia recomendada do curso.

      

        
1. Por que referenciar?
Referenciar dá crédito aos autores, permite que o leitor confira a fonte e evita plágio. Toda ideia, trecho de código ou figura que não seja sua deve ser citada no texto (ex.: KERNIGHAN; RITCHIE, 1989) e listada ao final em ordem alfabética.

        
2. Regras de ouro
  • Sobrenome do autor em MAIÚSCULAS, seguido do prenome.
  • Título do livro em negrito (ou itálico, sempre o mesmo padrão).
  • Alinhamento à esquerda, espaçamento simples, uma linha em branco entre referências.
  • Para sites: inclua URL e "Acesso em: dia mês ano".

        
3. Modelos

          
Livro:
SOBRENOME, Prenome. Título: subtítulo. Edição. Local: Editora, ano.

          
Artigo:
SOBRENOME, Prenome. Título do artigo. Revista, local, v. 1, n. 2, p. 10-20, ano.

          
Site / documentação:
AUTOR OU ENTIDADE. Título da página. Ano. Disponível em: URL. Acesso em: 1 jan. 2025.

PASSO A PASSO
Como usar esta página
Siga as etapas na ordem. Em poucos minutos você estará rodando seu primeiro programa.

      
    
        
  1. Instale as ferramentas
    Instale o compilador GCC/G++ (MSYS2 ou MinGW) e o Node.js. O script instalar_professor.ps1 faz isso para você (baixe na seção Downloads abaixo).
    2. 
        
  2. Abra o laboratório
    Dê duplo clique em abrir_laboratorio.bat. O navegador abrirá em http://127.0.0.1:47831. A página funciona apenas no seu computador.
    3. 
        
  3. Estude a Teoria
    Na aba Teoria, abra cada conceito, leia a explicação e estude o código de exemplo antes de executar.
    4. 
        
  4. Execute um programa
    Na aba C e C++, escolha um exemplo, clique em Executar, digite os dados pedidos no campo de entrada e acompanhe a saída. Depois altere o código no seu editor e rode de novo.
    5. 
        
  5. Leia as aulas e projetos
    As abas Aulas e projetos e Redes trazem aulas em HTML, cálculos e exercícios. Use a busca e os filtros para encontrar o tema.
    6. 
        
  6. Rode o Projeto IoT
    Na aba Projeto IoT, clique em Iniciar serviços (MQTT na porta 1883 e API na 3000). Ao terminar, clique em Parar serviços.
    7. 
        
  7. Explore Eletrônica e embarcados
    Veja códigos de Arduino, ESP32 e VHDL; simule os circuitos VHDL com o botão Simular.
    8. 
        
  8. Aprofunde nas Plataformas e Referências
    Use a aba Plataformas para conteúdos complementares e Referências para citar fontes corretamente.
    9.
