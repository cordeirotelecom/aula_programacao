Passo a passo Exercicios

Como as pecas se encaixam

Projeto: uma estufa inteligente. Um ESP32 mede temperatura e umidade, manda para a rede, os dados vao para um banco, aparecem num app, e voce liga um LED pelo app.

ESP32 (ou simulador)
   | MQTT  topico estufa/sala1/dados
   v
BROKER MQTT (broker.js)  <-- o "correio" que entrega mensagens
   |
   v
NODE-RED (ou ingestor.js)  calcula alerta (temp > 30)
   | HTTP POST
   v
API (api.js, porta 3000) --> BANCO SQLite (dados.db)
   |
   v
APP (navegador / celular) http://localhost:3000
   | botao LED --> POST /api/comando --> MQTT estufa/sala1/comando --> ESP32 acende o LED

O que e cada peca

  • MQTT: protocolo leve de publicar/assinar. Quem publica nao conhece quem assina.
  • Broker: servidor que recebe e distribui as mensagens por topico.
  • Node-RED: programacao visual por blocos que liga as pecas sem muito codigo.
  • API: porta de entrada HTTP para gravar e consultar dados.
  • SQLite: banco em um unico arquivo, sem instalar servidor.
  • App: pagina HTML/JS que consulta a API a cada poucos segundos.
Voce nao precisa da placa: o simulador.js faz o papel do ESP32.
