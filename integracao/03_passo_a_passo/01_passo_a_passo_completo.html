Conceitos Exercicios

Passo a passo: copie e cole no PowerShell

Cada passo que roda um servidor precisa de uma janela PowerShell propria (abra uma nova com o menu Iniciar > PowerShell). Nao precisa ser administrador.

Passo 1 - Instalar o Node.js (uma vez so)

winget install OpenJS.NodeJS.LTS --scope user

Feche e abra o PowerShell. Teste: node --version

Passo 2 - Instalar as bibliotecas do projeto

cd ".\integracao\02_projeto"
npm install

Passo 3 - Teste automatico (prova que tudo funciona)

npm run teste
Deve terminar com: TUDO CERTO - a integracao funciona.

Passo 4 - Janela 1: ligar o broker MQTT

cd ".\integracao\02_projeto"
npm run broker

Passo 5 - Janela 2: ligar a API + banco

cd ".\integracao\02_projeto"
npm run api

Passo 6 - Janela 3: ligar quem leva os dados ao banco

Escolha uma opcao (nunca as duas juntas):

Opcao A - ingestor (codigo, mais simples):

cd ".\integracao\02_projeto"
npm run ingestor

Opcao B - Node-RED (blocos visuais):

cd ".\integracao\02_projeto"
npm run nodered

Abra http://localhost:1880 e veja o fluxo "Estufa IoT" ja pronto. Clique em Deploy se aparecer.

Passo 7 - Janela 4: ligar o simulador do ESP32

cd ".\integracao\02_projeto"
npm run simulador

Passo 8 - Abrir o app

Start-Process http://localhost:3000

Voce ve temperatura, umidade, historico, e um botao para ligar/desligar o LED. Quando passa de 30 C aparece ALERTA.

No celular (mesmo Wi-Fi): abra http://IP-DO-PC:3000. Descubra o IP com ipconfig.

Passo 9 - Trocar o simulador pelo ESP32 real

  1. Arduino IDE: instale a biblioteca PubSubClient.
  2. Abra integracao\02_projeto\firmware\esp32_mqtt\esp32_mqtt.ino.
  3. Edite WIFI_SSID, WIFI_SENHA e MQTT_SERVIDOR (IP do PC).
  4. Pare o simulador (Ctrl+C) e faca Upload.
  5. Se nada chegar, o Firewall do Windows pode estar bloqueando a porta 1883.

Problemas comuns

  • Porta em uso: feche a janela antiga (Ctrl+C) e rode de novo.
  • App vazio: confira se as 4 janelas estao rodando.
  • Dados duplicados: voce ligou ingestor e Node-RED juntos.
