Aula 7 - Mobile first e design para toque

Mobile first

Projete primeiro para a tela pequena, depois amplie. Obriga a focar no essencial.

/* estilo base = celular */
.cartao { padding: 16px; }

/* telas maiores */
@media (min-width: 768px) {
  .cartao { padding: 24px; }
}

Nao esqueca no <head>:

<meta name="viewport" content="width=device-width, initial-scale=1">

Tamanho do alvo de toque

O dedo e muito mais impreciso que o mouse.

  • Minimo: 44 x 44 px (Apple) ou 48 x 48 dp (Google).
  • Espaco de 8px entre alvos vizinhos.
123 ← pequeno (24px): dificil de acertar
123 ← bom (48px)

Zona do polegar

Com uma mao, o polegar alcanca bem a parte de baixo da tela. Coloque as acoes principais embaixo (barra inferior) e deixe o topo para informacao.

Outras praticas mobile

  • Um objetivo por tela; poucas opcoes.
  • Teclado certo: type="number", type="email", type="tel".
  • Gestos nao devem ser a unica forma (arrastar precisa de alternativa por botao).
  • Feedback imediato ao toque (mudar cor, vibrar, mostrar "carregando").
  • Pense em sol forte, mao suja, internet ruim.
Exercicios
  1. Abra esta pagina, aperte F12 e ative o modo celular (Ctrl+Shift+M). Teste os botoes pequenos e os bons.
  2. Redesenhe uma tela sua pensando na zona do polegar.
