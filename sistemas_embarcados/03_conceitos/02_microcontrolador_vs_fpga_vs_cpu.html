Aula 02 - Microcontrolador vs FPGA vs CPU

Os tres "cerebros"

  • CPU / microprocessador (PC, celular, Raspberry Pi): muito poderoso, precisa de memoria e perifericos externos, roda sistema operacional (Linux, Windows).
  • Microcontrolador (MCU) (Arduino/AVR, ESP32, STM32): CPU + memoria + perifericos (GPIO, ADC, UART...) em um unico chip. Barato e de baixo consumo.
  • FPGA: chip cujo hardware e reconfiguravel. Voce descreve circuitos (em VHDL ou Verilog) e o chip vira esse circuito. Tudo acontece em paralelo.

Quando usar cada um?

Microcontrolador: controlar LED, ler sensor, automacao residencial, dispositivo a bateria, IoT simples.
FPGA: processar sinais muito rapido (video, radar, audio), protocolos com tempo exato em nanossegundos, muitas tarefas realmente simultaneas, prototipar um chip.
CPU/SBC (Raspberry Pi): interface grafica, camera com visao computacional, banco de dados, servidor web, Python.
Regra pratica: comece pelo microcontrolador. So suba para CPU se precisar de sistema operacional, e para FPGA se o MCU for lento demais ou precisar de paralelismo massivo.

Analogia

MCU = um cozinheiro muito habil que faz uma coisa de cada vez, bem rapido. FPGA = uma cozinha com varios fogoes, cada um ja ligado a uma receita, trabalhando juntos. CPU = um restaurante inteiro com gerente.

Exercicio: qual escolher? (a) termometro Wi-Fi a pilha; (b) filtro de audio em tempo real com 1 milhao de amostras por segundo; (c) painel de totem com video e touch.
