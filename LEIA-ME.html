1Instalar (so uma vez)

Conecte o pendrive. Abra o PowerShell: Menu Iniciar > digite PowerShell > Enter. Depois cole o comando:

$z = Get-PSDrive -PSProvider FileSystem | ForEach-Object { Join-Path $_.Root 'curso_programacao.zip' } | Where-Object { Test-Path $_ } | Select-Object -First 1; if (-not $z) { $z = Join-Path ([Environment]::GetFolderPath('Desktop')) 'curso_programacao.zip' }; $t = "$env:TEMP\curso"; Remove-Item $t -Recurse -Force -ErrorAction SilentlyContinue; Expand-Archive $z $t -Force; Get-ChildItem $t -Recurse -File | Unblock-File; powershell -NoProfile -ExecutionPolicy Bypass -File "$t\instalar_professor.ps1"; Start-Process ".\index.html"

Aguarde (precisa de internet para baixar GCC e Node.js). O curso fica em Documentos\programacao\curso_programacao.

Importante: depois de instalar, feche o PowerShell e abra um novo, para o computador reconhecer o gcc.
Sem internet ou PowerShell bloqueado? Extraia o ZIP e de duplo clique em index.html. As aulas em HTML funcionam sem instalar nada.

2Rodar programas em C e C++

Jeito mais facil (recomendado): de duplo clique em ABRIR_NO_VSCODE.bat. Abra qualquer arquivo .c, .cpp ou .html e aperte Ctrl+Shift+B: programas C/C++ compilam e rodam no terminal; aulas HTML abrem no navegador. Para rodar por nome: Ctrl+Shift+P → Tasks: Run Task → Rodar por nome... (ex: 01_ola_mundo, 03_enderecos_ip).
Pelo terminal: um unico comando serve para tudo (C, C++, aulas HTML de qualquer pasta). Abra a pasta do curso no Explorer, clique na barra de endereco, digite powershell e Enter. Depois: 
.\rodar.ps1 01_ola_mundo
.\rodar.ps1 03_enderecos_ip
Se aparecer erro de politica de execucao, use powershell -ExecutionPolicy Bypass -File .\rodar.ps1 NOME. Os comandos antigos (executar.ps1 e abrir.ps1) continuam funcionando.

Troque so o final: c ou cpp e o nome do programa.

Primeiro programa em C
powershell -ExecutionPolicy Bypass -File ".\executar.ps1" c 01_ola_mundo
Mesmo programa em C++
powershell -ExecutionPolicy Bypass -File ".\executar.ps1" cpp 01_ola_mundo
Simulacao de sistema embarcado
powershell -ExecutionPolicy Bypass -File ".\executar.ps1" c sim_01_maquina_estados
Calculo de rede (mascara, broadcast)
powershell -ExecutionPolicy Bypass -File ".\executar.ps1" c rede_08_passo_a_passo

APara o aluno

Cria Documentos\programacao\aluno com exercicios em branco, para fazer o codigo em sala.

Preparar o ambiente
powershell -NoProfile -ExecutionPolicy Bypass -File ".\preparar_aluno.ps1"
Rodar um exercicio do aluno
powershell -ExecutionPolicy Bypass -File "$([Environment]::GetFolderPath('MyDocuments'))\programacao\aluno\executar.ps1" c exercicio_01

?Se algo der errado

  • "gcc nao e reconhecido": feche o PowerShell e abra um novo.
  • "Nao encontrei o arquivo": confira o nome e se a pasta esta em Documentos\programacao\curso_programacao.
  • Download falhou: confira a internet e repita o passo 1.
  • Porta em uso (integracao): feche a janela antiga (Ctrl+C) e rode de novo.
