AbordagemTecnologiaVantagensDesvantagens

Por que o PWA neste curso?

  • Voce ja aprendeu HTML, CSS e JavaScript na pasta web.
  • Nao precisa instalar nada alem do navegador.
  • Funciona no celular Android e no iPhone.
  • Os conceitos de UX e de rede servem para qualquer outra abordagem depois.

O que e um PWA?

Progressive Web App e um site com tres extras:

  1. Manifest (manifest.json): nome, icone, cores. Permite "instalar".
  2. Service worker (sw.js): guarda arquivos para funcionar offline.
  3. HTTPS (ou localhost): exigencia de seguranca para os dois acima.
Cuidado: abrir o app no celular por http://192.168.x.x funciona como site, mas o navegador nao instala nem ativa service worker (nao e HTTPS). Para instalar de verdade, publique em HTTPS (ex.: GitHub Pages). Em localhost no PC tudo funciona.
Quando escolher outra: precisa de Bluetooth no iPhone, notificacoes em segundo plano ou de publicar na loja → Flutter ou React Native.
