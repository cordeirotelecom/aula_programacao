Aula 3 - Como o app fala com o dispositivo

ProtocoloComo funcionaBom paraCuidado
HTTP / RESTApp pede (GET /dados) e o dispositivo respondeRede local, projetos simples, este cursoO app precisa "perguntar" de tempos em tempos (polling)

HTTP: o que acontece

Celular                             ESP32
  | -- GET /dados ------------------> |
  | <-- 200 {"temperatura":27.5,...}  |
  | -- GET /led?estado=1 -----------> |
  | <-- 200 {"led":true}              |

MQTT: o que acontece

ESP32  --publica "estufa/temperatura" = 27.5 -->  BROKER  -->  Celular (assina "estufa/#")
Celular --publica "estufa/led" = ON ------------>  BROKER  -->  ESP32  (assina "estufa/led")

CORS: por que o navegador as vezes bloqueia

Se a pagina vem de um endereco e pede dados de outro (o ESP32), o navegador exige que o ESP32 responda com o cabecalho Access-Control-Allow-Origin: *. O firmware deste curso ja faz isso.
