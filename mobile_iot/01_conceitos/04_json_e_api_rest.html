Aula 4 - JSON e API REST

JSON: o idioma comum

JSON e um texto que organiza dados em chave: valor. Todo celular e todo ESP32 entendem.

{
  "temperatura": 27.5,
  "umidade": 61,
  "led": false
}
TipoExemplo
Numero27.5
Texto (aspas duplas)"Estufa"
Verdadeiro/falsotrue, false
Lista[1, 2, 3]
Objeto{"a": 1}

No JavaScript

var texto = '{"temperatura":27.5,"led":false}';
var dados = JSON.parse(texto);        // texto -> objeto
console.log(dados.temperatura);       // 27.5
var de_volta = JSON.stringify(dados); // objeto -> texto

API REST: rotas simples

RotaMetodoFazResposta
/dadosGETLe os sensores{"temperatura":27.5,"umidade":61,"led":false}
/led?estado=1GETLiga o LED{"led":true}
/led?estado=0GETDesliga o LED{"led":false}

Codigos de resposta: 200 deu certo, 400 pedido errado, 404 rota nao existe, 500 erro no dispositivo.

Teste a API sem app: com o ESP32 ligado, abra http://IP_DO_ESP32/dados no navegador do PC. Se aparecer o JSON, a parte do dispositivo esta pronta.
Exercicios
  1. Escreva o JSON de uma estufa com temperatura, umidade, luz e estado da bomba.
  2. Defina as rotas para uma fechadura (abrir, fechar, ler estado).
