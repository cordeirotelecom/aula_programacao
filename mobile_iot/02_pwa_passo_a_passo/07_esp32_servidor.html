Aula 7 (PWA) - O ESP32 como servidor da API

O firmware 04_firmware_esp32\esp32_servidor_http\esp32_servidor_http.ino faz o ESP32 responder as rotas que o app usa.

Passo 1: instale a Arduino IDE e o suporte ao ESP32. Siga a aula 05_instalar_arduino_ide da pasta esp32.
Passo 2: abra o .ino, troque SEU_WIFI e SUA_SENHA, escolha a placa e clique em Carregar.
Passo 3: abra o Monitor Serial (115200) e anote o IP, por exemplo 192.168.0.50.
Passo 4: teste no navegador: http://192.168.0.50/dados deve mostrar o JSON.
Passo 5: no app, Configurar → digite o IP → Salvar. Teste tambem controle_dispositivo (o LED da placa liga e desliga).

Como o firmware responde

servidor.on("/dados", aoPedirDados);   // GET /dados  -> JSON com sensores
servidor.on("/led", aoPedirLed);       // GET /led?estado=1 -> liga e responde o estado real
servidor.sendHeader("Access-Control-Allow-Origin", "*");   // CORS
Os sensores do firmware sao simulados. Veja a pasta esp32 para ligar sensores reais e aprender cada passo.
Exercicios
  1. Faca o LED da placa acender pelo app e confira se o botao mostra o estado real.
  2. Desligue o ESP32 e observe as mensagens de erro do app.
