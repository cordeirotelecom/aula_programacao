Aula 1 (PWA) - A pagina para celular

Passo 1: a linha mais importante. Sem ela o celular mostra o site minusculo, como se fosse um PC.
<meta name="viewport" content="width=device-width, initial-scale=1">
Passo 2: escreva o CSS do celular primeiro (mobile first). Resultado:
Temperatura

27,5 °C

.cartao { background: #fff; border-radius: 10px; padding: 12px; }
button  { min-height: 48px; font-size: 18px; }   /* alvo de toque */
Passo 3: deixe a barra de acoes na parte de baixo (zona do polegar):
.barra { position: fixed; left: 0; right: 0; bottom: 0; }
Passo 4: teste no PC com o modo celular: F12 → Ctrl+Shift+M.

Veja o resultado completo em 03_projetos\painel_sensores (arquivos index.html e estilo.css).

Exercicios
  1. Remova o meta viewport do projeto e compare no modo celular.
  2. Mude a cor do botao e o tamanho do valor.
