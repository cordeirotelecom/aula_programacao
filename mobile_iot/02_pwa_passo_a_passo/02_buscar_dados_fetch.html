Aula 2 (PWA) - Buscar dados com fetch

fetch faz um pedido HTTP. Como e assincrono, usamos async/await: "espere a resposta sem travar a tela".

Passo 1 - o codigo basico:
async function lerDados(endereco) {
  var resposta = await fetch(endereco + "/dados");
  if (!resposta.ok) throw new Error("HTTP " + resposta.status);
  return resposta.json();            // JSON -> objeto
}
Passo 2 - nunca esqueca o erro: o celular pode estar sem rede.
try {
  var dados = await lerDados("http://192.168.0.50");
  mostrar(dados);
} catch (erro) {
  mostrarErro("Sem conexao com o dispositivo.");
}
Passo 3 - limite de tempo: se o dispositivo nao responde, o app nao pode ficar esperando para sempre. O arquivo 03_projetos\logica.js usa AbortController (limite de 4 s).
