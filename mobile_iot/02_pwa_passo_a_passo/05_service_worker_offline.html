Aula 5 (PWA) - Service worker: funcionar sem internet

O service worker e um script que fica entre o app e a rede. Ele pode guardar arquivos (cache) e responder quando nao ha conexao.

Passo 1 - registrar (no script.js):
if ("serviceWorker" in navigator && location.protocol !== "file:") {
  navigator.serviceWorker.register("sw.js");
}
Passo 2 - guardar os arquivos na instalacao (sw.js):
var NOME_CACHE = "painel-sensores-v1";
var ARQUIVOS = ["./", "index.html", "estilo.css", "script.js"];

self.addEventListener("install", function (e) {
  e.waitUntil(caches.open(NOME_CACHE).then(function (c) { return c.addAll(ARQUIVOS); }));
});
Passo 3 - responder do cache quando a rede falhar:
self.addEventListener("fetch", function (e) {
  if (new URL(e.request.url).origin !== location.origin) return;  // ESP32 passa direto
  e.respondWith(fetch(e.request).catch(function () { return caches.match(e.request); }));
});
Importante: os dados do dispositivo (/dados) nao devem ir para o cache de arquivos; senao o app mostraria uma temperatura velha como se fosse atual. Por isso o sw.js ignora pedidos a outro endereco e o app guarda a ultima leitura no localStorage (com horario).

Testar

  1. Rode o servidor (aula 6) e abra http://localhost:8080/03_projetos/painel_sensores/index.html.
  2. F12 → aba Application → Service Workers: deve aparecer "activated".
  3. Marque Offline e recarregue a pagina: o app ainda abre.
Ao mudar um arquivo, aumente o numero de NOME_CACHE (v1 → v2) para atualizar o cache dos usuarios.
Exercicios
  1. Teste o modo Offline do navegador e descreva o que o app mostra.
  2. Acrescente um arquivo novo a lista ARQUIVOS e mude a versao do cache.
