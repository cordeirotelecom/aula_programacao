--------------------------------------------------------------
 PASSO 1 - INSTALAR (so uma vez)
--------------------------------------------------------------
 a) Conecte o pendrive.
 b) Menu Iniciar > digite PowerShell > Enter.
 c) Copie TODO o bloco abaixo, cole no PowerShell e aperte Enter:

$z = Get-PSDrive -PSProvider FileSystem | ForEach-Object { Join-Path $_.Root 'curso_programacao.zip' } | Where-Object { Test-Path $_ } | Select-Object -First 1; if (-not $z) { $z = Join-Path ([Environment]::GetFolderPath('Desktop')) 'curso_programacao.zip' }; $t = "$env:TEMP\curso"; Remove-Item $t -Recurse -Force -ErrorAction SilentlyContinue; Expand-Archive $z $t -Force; Get-ChildItem $t -Recurse -File | Unblock-File; powershell -NoProfile -ExecutionPolicy Bypass -File "$t\instalar_professor.ps1"; Start-Process ".\index.html"

 d) Aguarde (precisa de internet para baixar GCC e Node.js).
    O curso fica em: Documentos\programacao\curso_programacao
    Ao final abre a pagina inicial do curso no navegador.

 IMPORTANTE: depois de instalar, FECHE o PowerShell e abra um NOVO.
 So assim o computador reconhece o gcc.

 Sem internet ou PowerShell bloqueado?
    Extraia o ZIP (botao direito > Extrair tudo) e de duplo clique
    em index.html. As aulas em HTML funcionam sem instalar nada.


--------------------------------------------------------------
 PASSO 2 - RODAR PROGRAMAS EM C E C++
--------------------------------------------------------------
 Trocar so o final: c ou cpp  +  nome do programa.

 Primeiro programa em C:
powershell -ExecutionPolicy Bypass -File ".\executar.ps1" c 01_ola_mundo

 JEITO MAIS FACIL (recomendado):
   1) Duplo clique em ABRIR_NO_VSCODE.bat
   2) Abra qualquer arquivo .c, .cpp ou .html e aperte Ctrl+Shift+B
      (C/C++ compila e roda no terminal; HTML abre no navegador).
   3) Por nome: Ctrl+Shift+P > Tasks: Run Task > "Rodar por nome..."

 PELO TERMINAL: um unico comando serve para tudo. Abra a pasta do curso no
 Explorer, clique na barra de endereco, digite powershell e Enter:
   .\rodar.ps1 01_ola_mundo
   .\rodar.ps1 03_enderecos_ip
 (se der erro de politica: powershell -ExecutionPolicy Bypass -File .\rodar.ps1 NOME)
 Os comandos antigos (executar.ps1 e abrir.ps1) continuam funcionando.

 ONDE EXECUTAR os comandos antigos: rodam a partir da pasta do curso
 (onde esta o executar.ps1). Abra a pasta no Explorer, clique na barra de
 endereco, digite powershell e Enter. Ou: cd "CAMINHO\curso_programacao"

 Mesmo programa em C++:
powershell -ExecutionPolicy Bypass -File ".\executar.ps1" cpp 01_ola_mundo

 Simulacao de sistemas embarcados (C):
powershell -ExecutionPolicy Bypass -File ".\executar.ps1" c sim_01_maquina_estados

 Calculo de rede (mascara, broadcast):
powershell -ExecutionPolicy Bypass -File ".\executar.ps1" c rede_08_passo_a_passo

--------------------------------------------------------------
 SE ALGO DER ERRADO
--------------------------------------------------------------
 - "gcc nao e reconhecido": feche o PowerShell e abra um NOVO.
 - "Nao encontrei o arquivo": confira o nome e se a pasta esta em
   Documentos\programacao\curso_programacao.
 - Download falhou: confira a internet e repita o PASSO 1.
 - Porta em uso (integracao): feche a janela antiga (Ctrl+C) e rode de novo.
